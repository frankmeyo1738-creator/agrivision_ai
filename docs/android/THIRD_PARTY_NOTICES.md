# Android model/runtime provenance

- Converted model: derived solely from the project's existing trained MobileNetV3-Small checkpoint. Exact source/derived SHA-256 and versions are in `conversion_verification.json`; class order and local guidance are in the bundled model manifest.
- ONNX Runtime Android 1.23.2: Microsoft, MIT license, [official repository](https://github.com/microsoft/onnxruntime). Flutter and installed plugins retain their own notices; Flutter's Licenses page exposes packaged Dart notices when shown through its standard license facilities.
- RGB bilinear resampling semantics were implemented to match [Pillow's resampling implementation](https://github.com/python-pillow/Pillow/blob/main/src/libImaging/Resample.c). This project's Kotlin implementation uses a restricted crop and original code; Pillow is distributed under the [HPND/Pillow license](https://github.com/python-pillow/Pillow/blob/main/LICENSE). The algorithms are validated against the installed Pillow/TorchVision transform rather than assumed equivalent to Android Bitmap scaling.
- Five parity photographs: author PlantVillage source URLs and byte hashes are recorded in `conversion_verification.json`. They are for local conversion verification and are not packaged in the release APK. See `DATASET_RESEARCH.md` for the upstream license ambiguity and dataset limitations.
- Guidance is bundled from the existing backend's five-class educational descriptions. University-extension citations remain alongside the text; this is not new treatment guidance or a replacement for local diagnosis.
